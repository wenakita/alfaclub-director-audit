# Director — audit scope

Contracts for a two-phase official UERC20 + Uniswap V3 launch: `launch`, `open`, and `recoverUnopened`.

Start at [`src/director/AlfaClubDirector.sol`](src/director/AlfaClubDirector.sol). Other files here are interfaces, types, or contracts the Director deploys or calls. OpenZeppelin is not vendored.

This is not a full application repository. Deploy scripts, tests, and off-chain services are omitted.
